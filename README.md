# Superstore Sales Performance Dashboard

## 📊 Project Overview

This project presents an interactive Power BI dashboard developed to analyze sales and profitability performance using the Superstore Sales Dataset.

The dashboard transforms raw sales data into clear and interactive business insights through KPIs, charts, filters, and geographic analysis.

## 🎯 Objectives

- Analyze overall sales and profitability performance.
- Monitor key performance indicators (KPIs).
- Compare performance across regions, categories, and customer segments.
- Identify sales trends over time.
- Analyze product and sub-category performance.
- Provide an interactive and user-friendly reporting experience.

## 📌 Key Performance Indicators

The dashboard includes:

- Total Sales
- Total Profit
- Total Orders
- Total Customers
- Profit Margin
- Average Order Value

## 📈 Dashboard Features

### Page 1 – Sales Dashboard

The first page provides a high-level overview of business performance, including:

- Sales trend over time
- Profit by region
- Sales by category
- Top 10 sub-categories
- Geographic sales analysis
- Interactive filters

### Page 2 – Sales Details

The second page provides a more detailed analysis, including:

- Sales by ship mode
- Top 10 customers by sales
- Sales by segment
- Product details table
- Interactive filters for deeper analysis

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Data Visualization

## 🔍 Key Insights

The dashboard allows users to:

- Monitor sales and profit performance.
- Compare regional performance.
- Identify high-performing categories and sub-categories.
- Analyze customer and segment performance.
- Explore product-level sales information.
- Interactively filter and explore the data.
